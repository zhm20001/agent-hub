# Agent Hub 用户使用指南 (User Guide)

本指南面向人类开发者与操作人员，介绍如何通过 Web 监控工作台对子 Agent 进行派发、监控与生命周期干预。

---

## 1. 快速上手

### 1.1 启动服务
在项目根目录下运行：
```bash
npm run dev
```
开发服务器将默认监听在 `http://0.0.0.0:3000`。打开浏览器访问即可看到 DispatchDock 风格的暗色工作台。

### 1.2 界面语言切换
在页面顶部导航栏右上角，点击语言切换按钮：
- **`中文` / `English`**：点击可无缝切换界面语言（包括工单状态、过滤条件、操作按钮与表单提示）。
- 语言设置会自动保存在本地浏览器的 `localStorage` 中，刷新后依然有效。

---

## 2. 界面核心模块解析

工作台提供了 **“看板视图 (Kanban Board)”** 与 **“分栏详情 (Inspector)”** 两种展示模式，可通过顶部导航栏一键切换：

### 2.1 顶部状态栏 (Header)
- **双模切换**：支持在“看板视图”与“分栏详情”之间即时切换。
- **实时统计**：实时展示当前系统中 `Running`（运行中）、`Done`（已完成）、`Errors`（异常）的任务数量。
- **双语切换**：一键切换 `中文` / `English`。
- **派发子 Agent 按钮**：呼出高级任务配置弹窗。

### 2.2 人类直接创建任务表单 (Human Direct Dispatch)
在看板模式顶部常驻人类极速派发条：
- **一键快捷模板**：提供“代码结构分析与审计”、“检查 Git 工作区状态”、“重构优化核心逻辑”等开箱即用模板。
- **引擎选择**：支持一键在 `ZCode CLI` 和 `Bash Shell` 间快速切换。
- **极速派发**：填入需求并点击“⚡ 立即派发给 ZCode”，即可目睹新任务在后台启动，并直接加入看板泳道流转！

### 2.3 Swarm 敏捷任务看板 (Kanban Board)
分为三大泳道，自动响应后台 `.swarm-runs` 物理文件状态流转：
1. **⚡ 正在执行 (In Progress / Running)**：
   - 包含动态流光边框与绿色实时进程脉冲（`LIVE PROCESS`）。
   - 秒级跳动的运行时长计时器、PID 标识、Ticket 标签。
   - 子进程在后台执行期间持续在此泳道保持活跃。
2. **✅ 已完成 (Completed)**：
   - 任务以 exit 0 退出后，卡片自动跳动迁移至本列。
   - 标注总执行耗时与完成指标。
3. **⚠️ 已终止 / 异常 (Terminated & Failed)**：
   - 展示被看门狗超时清理、人工强杀或执行异常报错的任务。
- **点击抽屉检查**：点击看板上的任意卡片，即刻滑出右侧详情抽屉，实时追溯该任务的终端日志流（SSE）、执行简报（report.md）以及 Git Diff。

### 2.4 分栏时间线与深度检查器 (Inspector Mode)
提供传统的时间线列表与全高检查器，适合深度排查单个长周期任务的完整标准输出日志。

## 3. 任务派发与执行

点击右上角 **“派发子 Agent / Dispatch Subagent”**，在弹窗中配置参数：

| 参数项 | 说明 | 示例 / 可选项 |
| :--- | :--- | :--- |
| **工单号 (Ticket)** | 业务追踪标识，将贯穿在卡片、通知与简报中 | `T1`, `FIX-301` |
| **简要标题 (Label)** | 任务概述，用于快速识别 | `重构用户登录逻辑` |
| **执行适配器 (Adapter)** | 后台调用的子 Agent 引擎 | `zcode` (ZCode CLI) / `bash` (POSIX 脚本) |
| **权限运行模式 (Mode)** | 控制子 Agent 的执行策略 | `edit` (编辑代码), `build`, `plan`, `yolo` (无人值守) |
| **超时时间 (Timeout)** | 看门狗防死循环时间阈值（秒） | 默认 `1800` (30 分钟) |
| **任务指令 (Prompt)** | 发送给子 Agent 的完整独立提示词 | 包含所需修改的文件和具体要求 |

点击 **“立即脱钩派发 / Spawn Detached Run”**，系统会立即在 `.swarm-runs/<task_id>/` 创建专属目录，并以后台脱钩模式拉起子进程。

---

## 4. 任务强杀与干预

如果子 Agent 陷入异常逻辑或无限死循环：
1. 在右侧面板顶部点击 **“强杀进程 / Kill Process”** 按钮。
2. 系统将依据记录的 `pid` 调用跨平台进程树查杀指令（POSIX 下 `SIGKILL`，Windows 下 `taskkill /T /F`）。
3. 状态立即被标记为 `KILLED`，并在 `raw.log` 与 `report.md` 中记录操作员干预记录。
